# 塾の時間割作成（試作版）

生徒と講師の「希望曜日・時間・科目」をExcel（またはGoogleスプレッドシート）から読み込み、
集団授業と個別授業を含む週間時間割を自動で作ります。自動作成には Google の OR-Tools（CP-SAT）を使っています。

## 使い方

```bash
pip install -r requirements.txt
streamlit run app.py          # 画面で使う（http://localhost:8501）
python cli.py 入力.xlsx 出力.xlsx   # 画面なしで使う
python make_sample.py         # サンプル入力を作り直す
python -m pytest tests        # 必須条件が守られているかのテスト
```

## 入力（Excelのシート構成）

標準の入力はExcelファイルです。画面の「入力用の雛形をダウンロード」で雛形を取り、書き込んでアップロードします。
Googleスプレッドシートで作った場合も「ファイル → ダウンロード → Microsoft Excel」で保存すればアップロードできます。

| シート名 | 1行の単位 | 主な列 |
| --- | --- | --- |
| コマ設定（任意） | 1コマ | コマ, 開始, 終了 |
| 生徒_受講希望 | 1生徒×1科目 | 生徒ID, 氏名, 学年, 科目, 形式（集団/個別）, 週の回数, 希望講師（任意）, 固定（任意） |
| 生徒_空き時間 | 1生徒 | 生徒ID, 氏名, 月1, 月2, …（受講できるコマに○） |
| 講師_担当可能科目 | 1講師 | 講師ID, 氏名, 科目の列（例：英語, 数学, 物理, 化学, 国語）, 集団可, 個別可, 週の上限コマ（○で指定） |
| 講師_空き時間 | 1講師 | 講師ID, 氏名, 月1, 月2, …（出勤できるコマに○） |

科目は「講師_担当可能科目」シートの列見出しで決まります。講師ID・氏名・集団可・個別可・週の上限コマ・備考・メモ以外の列はすべて科目として読みます。
社会や理科、英検対策などを足したいときは、列を1つ足して担当できる講師に○を付けるだけです（時間割の色は自動で割り当てます）。
「生徒_受講希望」の科目は、この列見出しと同じ名前で書いてください。

画面の「入力用の雛形をダウンロード」で、今の曜日・コマ割に合わせた5シートの雛形（空き時間表は○を選択肢から選べる）を取れます。
読み込み済みの入力があれば、その生徒・講師のIDと氏名を入れた状態で出せるので、学期の切り替えで空き時間だけ取り直すときに使えます。

「生徒_受講希望」の「固定」列に「月1」や「月1、木2」のようにコマを書くと、その授業を必ずそのコマに入れます（希望講師があればその講師で固定）。
空き時間でないコマや、担当できる講師が空いていないコマは、注意を出して固定から外します。

見本は `sample/サンプル入力.xlsx`（架空の生徒30人・講師8人）です。

## Googleスプレッドシートから読む（Googleログイン）

Googleでログインすると、その人が見られるスプレッドシートを、共有設定を変えずにURLから読み込めます。
結果を元のスプレッドシートに書き戻すこともできます（「時間割_全体」などのシートを追加・上書き）。
ログインの情報はその画面（ブラウザのタブ）の中だけに持ち、保存しません。

設定していないときは、画面の「Googleスプレッドシート」に設定がまだである旨が出て、Excelでの入力だけが使えます。

設定手順（最初に1回）

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作る
2. 「APIとサービス → ライブラリ」で **Google Sheets API** を有効にする
3. 「OAuth 同意画面」を作る（種類は「外部」。テスト中は「テストユーザー」に使う人のGoogleアカウントを追加する）。スコープに `https://www.googleapis.com/auth/spreadsheets` を追加する
4. 「認証情報 → 認証情報を作成 → OAuth クライアント ID」で種類「ウェブ アプリケーション」を選び、
   「承認済みのリダイレクト URI」にアプリのURL（手元なら `http://localhost:8501`）を入れる
5. 表示されたクライアントIDとシークレットを `.streamlit/secrets.toml`（Gitで管理しない）に書く

```toml
[google_oauth]
client_id = "xxxx.apps.googleusercontent.com"
client_secret = "xxxx"
redirect_uri = "http://localhost:8501"
```

一般の塾に販売するときは、OAuth 同意画面を「本番」にしてGoogleの審査（スプレッドシートの読み書き権限のため）を受ける必要があります。

## 守るルール

必須（必ず守る）
- 生徒・講師とも空き時間のコマにだけ入れる
- 講師は担当できる科目・形式だけ受け持つ
- 同じコマに同じ生徒・講師が2つ入らない
- 個別：講師1人が同時に見る生徒は設定の人数まで。同時に個別授業をする講師の数はブース数まで
- 集団：科目×学年でクラスを作り、定員を超えたら複数クラスに分ける。同時に開く集団授業は教室数まで
- 生徒の週の回数と、講師の週の上限コマを超えない
- 生徒・講師とも、1日の授業は連続させる（間に空きコマを作らない）

優先（点数で調整、重みは `config.toml`）
- 希望講師に当てる / 個別は毎回同じ講師 / 同じ科目を同じ日に固めない / 講師の出勤日を少なく

入りきらない授業は「未配置」として、推定した理由と一緒に表示します。
「未配置」の「入らない理由を調べる」を押すと、必須条件（固定・連続授業・ブース数・教室数・講師の上限コマ・科目を混ぜない）を
1つずつ外して作り直し、それぞれ何コマ増えるか、どの授業が入るようになるかを表で出します。
固定どうしがぶつかって1コマも組めないときも、どの条件が原因かをここで確かめられます。

## 出力

画面で全体・講師列・生徒別・講師別・未配置を確認でき、Excelでダウンロードできます。
「講師列」は曜日ごとに、その日に授業がある講師だけを列に並べ、最後に手書き用の空の「予備」列を1列入れた表です。
Googleスプレッドシートから読んだときは、ログインしたまま元のスプレッドシートに「時間割_全体」「時間割_講師列」「時間割_生徒別」「時間割_講師別」「未配置」シートを書き込めます。

## 今の時間割をなるべく変えずに作り直す

書き出したExcelには、作り直し用の記録を隠しシート「再作成用」として入れています。
生徒の入れ替わりや空き時間の変更で作り直すときは、画面の「今の時間割をなるべく変えずに作り直す」でそのExcelを選んでから「時間割を作る」を押します。
前回と同じコマに入ると加点（同じ講師ならさらに加点）するので、変更が必要なところ以外はなるべく前回のままになります。
どれだけ優先するかは「優先条件の重み」の「前回の時間割と同じコマにする」で変えられます（授業を入れる加点より小さいので、入る授業の数は減らしません）。

## 条件の入力

画面の左側で、次の条件を数字で入力できます。

| 項目 | 内容 |
| --- | --- |
| 開講曜日 | 月〜日から選ぶ |
| コマ割 | 1日のコマ数・1限の開始・授業の長さ・休憩から自動で作る。コマごとの時刻は表で直せる |
| 教室 | 個別ブース数、集団教室数 |
| 個別授業 | 講師1人が同時に見る生徒数（1 = 1対1）、科目の違う生徒を同時に見てよいか |
| 集団授業 | 1クラスの定員 |
| 優先条件の重み | 希望講師・同じ講師・空きコマなどをどれだけ重視するか |

入力に「コマ設定」シートがあれば、そのコマ割が最初に入ります。
「この条件を既定にする」を押すと `config.local.toml` に保存され、次回から最初に入ります。このファイルはGitで管理しないので、`git pull` で上書きされたり、pullを止めたりしません。`config.toml` は全員共通の初期値です。
生徒・講師の空き時間シートの列（月1, 月2 …）は、入力したコマ割に合わせてください。

## 構成

- `timetable/loader.py` 設定と入力（Excel）の読み込み・検証
- `timetable/template.py` 入力用Excelの雛形
- `timetable/google_sheets.py` Googleログイン（OAuth）とスプレッドシートの読み書き
- `timetable/solver.py` 時間割の自動作成（OR-Tools）
- `timetable/output.py` 表の作成と書き出し
- `timetable/settings_io.py` 画面で入力した条件（コマ割の生成・確認・保存）
- `app.py` 画面（Streamlit）／ `cli.py` コマンドライン版
