# 希望を集める Google フォーム

生徒の「受講したい科目・回数・通塾できる時間」と、講師の「担当できる科目・形式・出勤できる時間」を
Google フォームで集め、アプリの入力と同じ5シートにまとめる Google Apps Script です（`forms.gs`）。

## できること

| フォーム | 質問 |
| --- | --- |
| 受講希望アンケート（生徒用） | 氏名 / 学年 / 受講したい科目と週の回数（科目ごとに「受けない・集団 週1回…個別 週3回」から選ぶ） / 通塾できる時間（30分ごと×曜日に○） / その他の要望 |
| 出勤可能日アンケート（講師用） | 氏名 / 担当できる科目 / 担当できる形式（集団・個別） / 1週間の最大コマ数 / 出勤できる時間（30分ごと×曜日に○） |

回答はスプレッドシートに集まり、メニュー「時間割 → 回答を入力シートにまとめる」で
`コマ設定` `生徒_受講希望` `生徒_空き時間` `講師_担当可能科目` `講師_空き時間` の5シートを作ります。

- 同じ氏名で2回以上答えたときは、最後の回答を使います（空白の有無は区別しません）
- 生徒ID・講師IDは S001, T001… を最初に回答した順に振ります。まとめ直しても、前にまとめたシートと同じ氏名には同じIDを使います
- `生徒_受講希望` に手で書いた「希望講師（任意）」「固定（任意）」は、まとめ直しても引き継ぎます。それ以外を手で直した場合は、まとめ直すと上書きされます
- 生徒の「その他の要望」は `生徒_受講希望` の「要望」列に入ります（アプリは読みません。希望講師や固定に書き直すときの参考用）

## 準備（最初に1回）

1. Google ドライブで新しいスプレッドシートを作る（名前は例えば「時間割 入力」）
2. メニュー「拡張機能 → Apps Script」を開き、最初からある `コード.gs` の中身を消して `forms.gs` を丸ごと貼り付け、保存する
3. ファイルの上の方にある `CONFIG` を塾に合わせて直す
   - `juku`：フォームの題名に入る塾名
   - `season`：講習のフォームを作る・まとめるときに使う。`name`（講習の名前）・`start` `end`（初日・最終日、`'2026-12-24'` の形）・`closedWeekdays`（休みの曜日）・`closedDates`（休みの日）・`komas`（講習のコマ）・`maxTimes`（1科目で選べる講習期間中の回数の上限）をアプリの講習の条件と同じにする。
     空き時間の列は「12/24(木)16:00」、受講希望は「回数」、講師の上限は「上限コマ」の列になる
   - `season.times`：講習の空き時間を、30分ごとではなく時間帯で聞くときに書く
     - 全日同じ時間帯：`['13:00~15:00', '15:00~17:00', '17:00~19:00', '19:00~22:00']` → 行が時間帯・列が日付の表で聞く
     - 日によって違う時間帯：`{ '12/24': ['13:00~15:00', '15:00~17:00'], '12/26': ['10:00~12:00'], '*': [ほかの日の時間帯] }` → 「12/24(木) 13:00〜15:00」のような選択肢から選ぶ
     - 空き時間の列は「12/24(木)13:00〜15:00」になる。アプリは、コマ（90分）の時間が○の時間帯にすっかり入るとき（2つの時間帯にまたがるなら両方に○があるとき）にそのコマへ授業を入れる
   - `days` と `komas`：アプリの「開講曜日」「コマ割」と同じにする
   - `slotMinutes`：空き時間を聞く刻み（分、ふつうは30）。最初のコマの開始から最後のコマの終了までを、この刻みで聞く。
     `生徒_空き時間` `講師_空き時間` の列は「月16:00」（16:00〜16:30）のような30分ごとになり、アプリはコマ（90分）にかかる枠すべてに○があるときだけ、そのコマに授業を入れる
   - `subjects`：科目（アプリの `講師_担当可能科目` の科目列になる）
   - `grades`：学年の選択肢
   - `maxTimesPerWeek`：生徒が1科目で選べる週の回数の上限
4. 上の関数の選択欄で `フォームを作る`（通常授業）か `講習のフォームを作る` を選んで「実行」を押す（2回目からはメニュー「時間割 → フォームを作る（通常授業）／（講習）」でも作れる）。
   講習のフォームは題名の最後に講習の名前（例：「〇〇塾 受講希望アンケート（生徒用） 冬期講習」）が付く。初回は Google の許可画面が出るので、自分のアカウントで許可する
   （「このアプリは確認されていません」と出たら「詳細 → 〜（安全ではないページ）に移動」）
5. スプレッドシートに戻ると、生徒用・講師用のフォームのURLが表示される。回答用のURLを生徒・講師に送る

スプレッドシートを開き直すと、メニューに「時間割」が出ます。フォームのURLは「時間割 → フォームのURLを表示」でいつでも見られます。

## 回答を時間割に使う

1. スプレッドシートのメニュー「時間割 → 回答を入力シートにまとめる」を押す
   - このスプレッドシートに回答が届くフォームをすべて読み、**題名に「講習」が入ったフォーム**の回答は講習の入力シート（`講習_生徒_受講希望` など、頭に「講習_」）、入っていないフォームの回答は通常授業の入力シート（`生徒_受講希望` など）にまとめる
   - 講師のフォームかどうかは、題名の「講師」か「担当できる科目」の質問で見分ける
   - 手で作ったフォームで質問の見出しが違っても、氏名は最初の記述式の質問、空き時間は最初のチェックボックスのグリッド（行=時刻、列=曜日や「12/20 日」のような日付）から読む
2. 選び忘れ（科目なし・空き時間なし）があれば一覧で出るので、必要なら本人に聞く
3. アプリの「Googleスプレッドシート」でこのスプレッドシートのURLを読み込む
   （Googleログインを設定していないときは「ファイル → ダウンロード → Microsoft Excel」で保存してアップロードする）
4. 希望講師や固定のコマを入れたいときは、`生徒_受講希望` の「希望講師（任意）」「固定（任意）」に書いてから読み込む

回答が増えたら、もう一度「回答を入力シートにまとめる」を押せば作り直せます。

## 新しい学期・講習を始めるとき（前の回答を使わない）

学期が変わると生徒や講師も変わるので、前の期の回答は新しい時間割に入れません。
メニュー「時間割 → 新しい期を始める（通常授業）」（講習なら「新しい講習を始める」）を押し、回答を使い始める日付を「2026/8/25」の形で入れてください（空のままなら今日）。

- その日付より前に送られた回答は、「回答を入力シートにまとめる」で使いません（同じフォームを使い回しても、2学期には1学期の回答が入りません）
- 前の期にまとめたシートの「希望講師（任意）」「固定（任意）」と、生徒ID・講師IDも引き継ぎません（IDは S001 から振り直します）
- 通常授業と講習は別々に区切ります。冬期講習を始めても、通常授業の回答はそのまま使います
- 「フォームを作る」で新しいフォームを作ったときも、日付を聞きます（キャンセルすれば今までどおり）。日付は何度でも入れ直せます
- まとめたときの知らせに「〜以降の回答だけを使いました（それより前の◯件は使っていません）」と出ます


## 科目やコマ割を変えたとき

`CONFIG`（講習の期間を変えるときも）を直してから「時間割 → フォームを作る」でフォームを作り直してください（前のフォームと回答は残りますが、まとめるのは新しいフォームの回答です）。
今のフォームのまま質問を手で直す場合は、質問の見出し（`Q` に書いた文言）を変えないでください。見出しで回答を探しています。
